# maternal-thyroid-phenotype
母婴队列甲状腺表型分类流程
## 项目简介
基于母婴NIPT大队列多源临床数据，整合甲状腺功能实验室指标（FT4/TSH/TPOAb）与临床诊断文本，实现分孕期分层判定、单人多条记录合并、共病优先级映射的完整表型编码流程。
## 分析逻辑
1. 导入分娩信息、甲功化验单、病历诊断多份 Excel 数据；
2. 按照孕早 / 中 / 晚、产后不同参考范围，划分 FT4、TSH 高低，同时判断 TPOAb 是否偏高；
3. 单条检测记录根据化验结果 + 病历文字匹配，生成基础疾病编号；
4. 同一个 NIPTID 有多条产检记录，把所有疾病编号合并；
5. 去掉单纯健康人群的 0 开头编号，只保留甲状腺相关疾病；
6. 存在多种甲状腺病时按规则分配统一编码，有结节、癌症优先归类；
7. 生成每个人唯一最终疾病编码；
8. 筛选分类不清、病历同时写甲亢 + 甲减等异常样本方便后续核查。
